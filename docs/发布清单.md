## 三、你需要手动做的事

### 1. 替换占位符

把 `hanqingyan3293` 替换成你的 GitHub 用户名（3 个文件）：

| 文件 | 位置 |
|---|---|
| `README.md` | 第 1 段 `git clone` 地址 |
| `src/DittoShell.App/DittoShell.App.csproj` | `<RepositoryUrl>` |
| `src/DittoShell.App/Views/SettingsPage.xaml` | 关于页两个链接 |

### 2. 推送到 GitHub

```bash
cd D:\File\Data\ditto

# 初始化（如果还没）
git init
git branch -M main

# 添加远程
git remote add origin https://github.com/hanqingyan3293/ditto-shell.git

# 检查将要提交的文件（重要！）
git add -A
git status --short

# 确认无误后提交
git commit -m "feat: DittoShell v1.0.0 — modern UI shell for Ditto"

# 推送
git push -u origin main
```

**提交前必看**：`git status --short` 的输出里**不应该**出现：
- `data/` 下的任何文件
- `backup/` 下的任何文件
- `reference/` 下的任何文件
- `*.db` / `*.log` / `config.json`
- `publish/` / `bin/` / `obj/`

**如果出现了**，说明 `.gitignore` 没生效，先检查再提交。

### 3. 创建 Release

4. 上传 `DittoShell-v1.0.0-win-x64.zip`
5. 描述用下面的内容


### 4. Release 描述（可直接复制）

```markdown
## DittoShell v1.0.0

给 [Ditto](https://github.com/sabrogden/Ditto) 剪贴板管理器做的现代界面外壳。
**不修改 Ditto 本体** —— Ditto 继续在后台抓取和粘贴。

### 功能

- 三栏界面（分组树 / 条目列表 / 详情预览），三栏都能拖动调整
- 真正的标签系统（多对多，可筛选）
- 智能分类（代码 / 链接 / 凭据 / 图片 / 命令 / 文件 / 长文本 / 邮箱 / 文本）
- 无限层级分组 + 树形连接线 + 拖动排序 + 拖动移入
- 分组导出（JSON / 纯文本）
- 隐私模式（列表打码 + AI 不可见）
- 可选 AI 检索与整理（DeepSeek API，**默认关闭**）
- 浅色 / 深色主题
- 中英双语

### 安装

1. 确保已安装并运行 [Ditto](https://ditto-cp.sourceforge.io/)
2. 下载 `DittoShell-v1.0.0-win-x64.zip`，解压到任意目录
3. 双击 `DittoShell.exe`

**不需要单独安装 .NET** —— 已自包含运行时。

### 系统要求

- Windows 10 1809+ / Windows 11（x64）
- Ditto 已安装并运行

### 已知问题

- 右键菜单在某些位置会出现在鼠标**左侧**而非右下（详见 [交接文档](docs/右键菜单定位问题-交接文档.md)）
- 分组排序偏好不持久化（重启恢复默认）

### 许可

GPL v3（与 Ditto 一致）
```
