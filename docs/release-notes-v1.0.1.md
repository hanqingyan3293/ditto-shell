## DittoShell v1.0.1

给 [Ditto](https://github.com/sabrogden/Ditto) 剪贴板管理器做的现代界面外壳。
**不修改 Ditto 本体** —— Ditto 继续在后台抓取和粘贴，DittoShell 只做前端。

---

### 新增

**AI 对话 · 权限模式**

三档权限，输入框下方一个下拉切换：

| 模式 | 允许 |
|---|---|
| 🛡️ 安全（默认） | 改数据前弹确认 |
| ⚡ 完全权限 | 直接执行，不询问 |
| 🔒 只读 | 只能查，不能改 |

**AI 对话 · 计划模式**

点「📋 计划」，AI 先探索出方案，你批准后才执行。

- 计划模式下**强制只读**（比 DSH 更严格）
- 方案评审对话框，可写修改意见让它继续规划
- 批准后自动退出计划模式

**AI 对话 · 目标模式**

点「🎯 目标」，让 AI 分多轮自动完成一个长期目标。

```
🎯 把所有重复的条目清理掉，每组只保留最新的
   第 3/30 轮 · 180 条    [编辑] [清除] [暂停]
```

- 每轮最多处理 200 条
- 默认最多 30 轮
- AI 主动调 `update_goal` 报告结果（complete / continue / blocked）
- 受阻需连续 3 轮同一原因才停下
- 重启后自动恢复

**AI 整理 · 标签收敛**

之前的 AI 整理会创造几百个标签，失去分类意义。现在：

- **标签词表**：AI 先分析生成 20-40 个标签，分类时只能从词表选
- **4 种标签模式**：覆盖 / 只补空白 / 追加 / 完全不动
- **6 个保护开关**：保留手动分类、跳过凭据、跳过图片、跳过隐私…
- **自然语言约束**：写「不要改凭据的标签，标签控制在 30 个以内」，解析成开关
- **执行前预览**：显示将处理 N 条，跳过 M 条（按原因分组 + 样例）
- **先算完再写**：中途取消不改任何数据

**标签管理**

设置 → 数据 → 标签：

- 显示总数 / 空标签数 / 有引用数
- **一键清理空标签**（实测清掉 2,471 个孤儿标签）
- 标签管理对话框：按引用数排序、搜索、逐个删除

**分组功能**

- 右键菜单 11 项：重命名 / 新建子组 / 移到顶层 / 复制组名 / 只搜这个组 / 导出 / 移到未归类 / 清空 / 删除
- **导出分组**：JSON 或纯文本
- **拖动排序**：同层分组之间拖，有上/下插入线 + 移入高亮
- **拖动移入**：拖条目到分组，支持多选
- 全部展开 / 折叠、按名称/数量排序

**「移到分组」浮窗重做**

- 树形缩进 + `├─`/`└─` 连接线 + 字号分级
- 搜索框（输入即筛选，自动展开匹配项祖先）
- 可折叠
- 8px 圆角 + 20px 阴影

**全新图标**

黑白配色，继承原版 Ditto 的视觉语言（深色圆角方块 + 两条 -14.9° 倾斜的白斜线 + 细线外框）。

7 个尺寸（16~256）打包成单文件 `app.ico`。

### 修复

**右键菜单出现在左侧**

之前右键菜单总是弹在鼠标**左侧**而不是右下，而且二级菜单（`组 → 移到分组`）同样向左展开。

**根因**：Windows 的 `SystemParameters.MenuDropAlignment` 系统设置（「菜单右对齐」，用于左手操作）被开启了。WPF 会读这个值来决定菜单展开方向。

**修法**：适配 WPF 的私有缓存字段 `_menuDropAlignment`，只改变本外壳的菜单方向，保留原生键盘导航、点击行为和屏幕边缘避让。

```csharp
var cache = typeof(SystemParameters).GetField("_menuDropAlignment",
    BindingFlags.NonPublic | BindingFlags.Static);
cache.SetValue(null, false);   // 强制左开（光标右下）
```

同时提供 `--verify-menus` 独立回归入口，升级 WPF 时可以检查这个私有字段是否仍兼容。

### 改进

**隐私保护**

- 列表打码改成**保留头尾**（`Viewed REA·················ae-roa`），不再是全黑点
- AI 的 **19 个工具全部过滤隐私条目**（之前 `search` / `get_context` / 分组统计都会泄漏）
- 预览区加「👁 查看原文」按钮，临时显示

**性能**

- **AI 整理应用**：2,088 条从「几分钟无响应」变成 **15 秒内完成**
  - 原因：之前逐条写标签和日志（4,176 次独立事务），现在批量事务
  - 加进度条 + 阶段文字 + 按钮状态反馈
- 批量删除条目只备份一次（之前每条备份 856MB）

**数量显示**

- 侧栏「代码」以前一直显示 0（`CountKey` 是空字符串），现在正确
- 「图片」以前也显示 0（`imageIds` 没预加载），现在正确

**备份策略**

- 从「每次操作都备份」改成「**当天只备份一次**」
- 保留份数从 10 降到 2
- 新增备份管理页（设置 → 备份）：查看列表、逐份删除、一键清理

**启动器**

`启动.bat` 重写：

- 先杀旧进程（之前不杀，构建失败后仍启动旧 exe，导致「改了没效果」）
- 构建后比对 exe 与源码时间戳，旧了就报错不启动
- 编码修正（bat 用 GBK，ps1 用 UTF-8 BOM）

### 安装

1. 确保已安装并运行 [Ditto](https://ditto-cp.sourceforge.io/)
2. 下载 `DittoShell-v1.0.1-win-x64.zip`
3. 解压到任意目录（**不要放在 Ditto 的安装目录**）
4. 双击 `DittoShell.exe`

**不需要单独安装 .NET** —— 已自包含 .NET 8 运行时。

### 从 1.0.0 升级

直接覆盖即可。`data/` 目录（标签、配置、AI 会话）会自动保留并迁移。

侧栏会自动升级到 `user_version = 4`（新增目标模式表）。
