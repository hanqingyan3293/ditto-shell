## DittoShell v1.0.0

给 [Ditto](https://github.com/sabrogden/Ditto) 剪贴板管理器做的现代界面外壳。
**不修改 Ditto 本体** —— Ditto 继续在后台抓取和粘贴，DittoShell 只做前端。

---

### 功能

**界面**
- 三栏布局（分组树 / 条目列表 / 详情预览），三栏都能拖动调整宽度
- 快速面板（`Ctrl+``）不打断当前工作
- 浅色 / 深色主题

**搜索**
- 全文搜索、`#1234` 按 ID、`tag:工作`、`from:chrome`，多条件 AND

**分组**
- 无限层级（组 / 子组 / 孙组…）
- 树形连接线 `├─` `└─` + 字号分级
- 拖动排序、拖动条目进组
- 导出分组为 JSON / 纯文本
- 右键：重命名 / 新建子组 / 复制组名 / 组内搜索 / 清空 / 删除

**智能分类**
- 9 个类型：代码 / 链接 / 凭据 / 命令 / 图片 / 文件 / 长文本 / 邮箱电话 / 文本
- 自动识别，侧栏一键筛选

**隐私**
- 标记为隐私的条目：列表打码（保留头尾）、AI 完全不可见
- 预览区可临时「查看原文」
- 独立「隐私」分类

**AI（可选，默认关闭）**
- 自然语言检索（如「上周的改枪码」）
- 智能整理：AI 分析样本 → 生成分类方案 → 你确认 → 批量归类
- 摘要 / 标签建议
- 支持 DeepSeek API

### 安装

1. 确保已安装并运行 [Ditto](https://ditto-cp.sourceforge.io/)
2. 下载 `DittoShell-v1.0.0-win-x64.zip`
3. 解压到任意目录（**不要放在 Ditto 的安装目录**）
4. 双击 `DittoShell.exe`

**不需要单独安装 .NET** —— 已自包含 .NET 8 运行时。

---

### 系统要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 1809+ / Windows 11（x64） |
| Ditto | 已安装并运行中 |
| 磁盘 | 约 200 MB（程序 + 运行时） |

---

### 你的数据在哪

```
DittoShell/
├── data/
│   ├── sidecar.db      # 标签、AI 会话、整理记录
│   ├── config.json     # 界面配置
│   └── menu.log        # 调试日志（可删）
└── backup/             # 修改 Ditto.db 前的自动备份
```

**不会上传任何数据**，除非你主动使用 AI 功能（那时只发送你选中的条目内容）。
