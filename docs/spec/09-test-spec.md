# 09 · 测试与验收

> 原则：**数据层用单测守住，界面用手动清单过。** 不做 UI 自动化。

---

## 1. 性能基准（必须达标才能发布）

| 指标 | 目标 | 实测（验证阶段） | 测量方式 |
|---|---|---|---|
| 冷启动：按键 → 面板可见 | ≤ 300 ms | 待测 | 秒表打点，20 次取中位 |
| 主界面打开 | ≤ 400 ms | 待测 | 同上 |
| 首页加载 50 条 | ≤ 20 ms | **10.8 ms** ✅ | 内置计时 |
| 搜索（6 千条） | ≤ 20 ms | **5.7–9.1 ms** ✅ | 内置计时 |
| 搜索（5 万条，压测） | ≤ 80 ms | 估算 ~55 ms | 造测试库 |
| 图片首显（8.6MB） | ≤ 150 ms | 待测 | 内置计时 |
| 内存峰值（滚动 200 条后） | ≤ 80 MB | 待测 | 任务管理器 |
| 常驻内存（空闲） | ≤ 50 MB | 待测 | 同上 |
| 安装体积 | ≤ 60 MB | 待测 | 打包后 |
| 连续粘贴 100 次成功率 | 100% | 待测 | 自动化脚本 |

## 3. 手动验收清单

### 3.1 阶段 1 · 只读前端

- [ ] 按 `Ctrl+\`` 面板 300ms 内出现
- [ ] 首屏显示最近条目，序号 1–10 正确
- [ ] 输入中文能搜到（含 2 字词，如「配装」）
- [ ] 输入 `/` 弹出筛选面板，选「按类型」→ 图片 → 列表只剩图片
- [ ] `Enter` 粘贴到记事本，**格式正确**（富文本带格式、图片能粘）
- [ ] `Ctrl+Enter` 纯文本粘贴，格式被剥离
- [ ] 图片条目显示真实缩略图（不是 `CF_DIB` 字样）
- [ ] `Esc` 关闭，焦点回到原窗口
- [ ] 面板贴屏幕右边缘时自动内缩
- [ ] 150% DPI 下文字清晰、无错位

### 3.2 阶段 2 · 分组与标签

- [ ] `Tab` 弹出分组树，能看到「枪械库 → KC17」两层
- [ ] 新建子组出现在正确父级下
- [ ] 重命名后旧界面（Ditto）也能看到新名字
- [ ] 删除分组后条目回到「未归类」，内容还在
- [ ] 拖动组到另一个组下，层级变化
- [ ] 拖动到自己子组被拒绝并提示
- [ ] 加标签后，`tag:周报` 能搜到
- [ ] 点 `⋯` 展开预览，右侧显示格式/AI 摘要

### 3.3 阶段 3 · AI

- [ ] 未配 Key 时 AI 入口置灰
- [ ] 配置 Key → 测试连接成功，显示模型名与延迟
- [ ] 选中一条文本 → AI 摘要正常返回
- [ ] 选中敏感条目 → 被阻止，提示打码
- [ ] 断网时 3s 内失败并提示
- [ ] 关闭面板会取消进行中的请求

### 3.4 阶段 4 · 稳定性

- [ ] 连续改分组 50 次，Ditto 无异常，`PRAGMA integrity_check` 通过
- [ ] 杀掉外壳进程，Ditto 正常
- [ ] 杀掉 Ditto，外壳提示并可一键重启
- [ ] 模拟磁盘满，写操作被阻止且提示清晰
- [ ] 把 sidecar 改坏，启动后自动重建并提示

## 4. 回归检查（每次改动后跑）

| # | 检查 | 命令/操作 |
|---|---|---|
| R01 | Ditto 库完整性 | `PRAGMA integrity_check` |
| R02 | 条目数未异常减少 | `SELECT COUNT(*) FROM Main` 对比改动前 |
| R03 | 分组树结构未破坏 | 对比 `bIsGroup=1` 的行数与父子关系 |
| R04 | 备份文件已生成 | 检查 `backup/` 最新文件时间 |
| R05 | 日志无 ERROR | 检查 `data/logs/` 当日文件 |
