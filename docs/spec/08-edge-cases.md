# 08 · 边界与异常清单

> 每一条都必须是实现时要处理的。写代码前逐条对照。

## A. 数据边界

| # | 场景 | 表现要求 | 处理 |
|---|---|---|---|
| A01 | 库为空（0 条） | 不报错 | 空状态插画 + 「去复制点什么」 |
| A02 | 只有 1 条 | 正常 | 序号 1，列表只有一行 |
| A03 | 单条文本 50 万字符 | 不卡顿 | 列表只显示前 2 行；预览面板按需加载 + 虚拟滚动 |
| A04 | 单张图片 8.6MB | ≤150ms 显示 | 后台解码 + 缩略图；原始图只在「另存为」时读全量 |
| A05 | 图片 DIB 损坏 | 不崩溃 | 灰色占位图 + 日志 warning |
| A06 | `mText` 为 NULL | 不崩溃 | 显示「(无预览)」 |
| A07 | 条目被 Ditto 自动删除（标签成孤儿） | 不报错 | 启动对账清理；运行中查不到则跳过 |
| A08 | 内容含 `%` `_` `\` | 搜索准确 | LIKE 前转义 + `ESCAPE '\'` |
| A09 | 内容含 emoji / 生僻字 | 正常显示 | UTF-16 存储，WPF 原生支持；字体回落 |
| A10 | 内容含换行/制表符 | 列表单行显示 | 换行转空格，制表符转 2 空格 |
| A11 | 内容含控制字符 `\u0000` | 不截断字符串 | 显示前过滤 |
| A12 | 同一内容重复 100 次 | 靠 Ditto 去重 | 外壳不额外去重 |

## B. Ditto 状态

| # | 场景 | 处理 |
|---|---|---|
| B01 | Ditto 未运行 | 「Ditto 未运行」+ 「启动」按钮；启动后自动恢复 |
| B02 | Ditto 正在写库（`SQLITE_BUSY`） | 重试 3 次（50/100/200ms），仍失败提示"稍后再试"，**不弹窗** |
| B03 | `Ditto.db` 被独占锁 | 只读打开失败 → 提示「请关闭占用程序」+ 重试按钮 |
| B04 | Ditto 路径变更（用户移动了目录） | 启动探测失败 → 引导卡「重新选择 Ditto 目录」 |
| B05 | Ditto 升级后表结构变化 | 启动自检失败 → **降级为只读模式**，禁用分组写入 |
| B06 | 用户同时启动两个外壳实例 | Mutex 拦截，第二个实例唤起第一个后退出 |
| B07 | Ditto 热键与外壳冲突 | 首次启动检测 → 中文引导卡 → 「我改好了，重新检测」 |
| B08 | 用户在 Ditto 里手动改了数据 | 定时器检测 `MAX(lID)`；面板可见时刷新 |

## C. 系统环境

| # | 场景 | 处理 |
|---|---|---|
| C01 | 150% / 200% DPI | 全 DIP 布局；图片按物理像素 |
| C02 | 多显示器、不同 DPI | 面板显示在鼠标所在屏；`PerMonitorV2` |
| C03 | 面板贴近屏幕边缘 | 自动翻转/内缩，不超出工作区 |
| C04 | 任务栏在顶部/侧边 | 用 `SystemParameters.WorkArea` 计算 |
| C05 | 系统切到深色 | 跟随（除非用户锁定） |
| C06 | 输入法激活（中文组词中） | 不截获数字键（检测 `ImeComposition` 状态） |
| C07 | 远程桌面 / 无 GPU | 关闭动画与阴影（检测 `RenderCapability.Tier`） |
| C08 | 屏幕锁定后解锁 | 热键可能失效 → 重新注册 |
| C09 | 系统时间被改 | 相对时间显示用 `DateTimeOffset`，异常值显示绝对时间 |

## D. 用户操作

| # | 场景 | 处理 |
|---|---|---|
| D01 | 连续快速按热键 10 次 | 幂等：只切换一次；有节流（100ms） |
| D02 | 边搜边按 Enter | 用当前选中项；若无选中则用第一条 |
| D03 | 粘贴后立刻再按热键 | 面板重新出现，焦点在搜索框 |
| D04 | 删除分组后又想恢复 | 不删内容，条目回「未归类」，可再移回 |
| D05 | 误删条目 | 提供「撤销」（5 秒内，仅限本次会话删除的） |
| D06 | 拖动分组到自己的子组 | 拒绝 + 提示「不能移到自己的子分组」 |
| D07 | 分组重命名为空 | 拒绝 + 保持原名 |
| D08 | 分组重名 | 允许（Ditto 也允许），但提示同名存在 |
| D09 | 输入 `/` 后想搜含 `/` 的内容 | `//` 转义为字面斜杠 |
| D10 | 搜索框粘贴超长文本（10 万字） | 截断到 200 字符并提示 |

## E. 网络与 AI

| # | 场景 | 处理 |
|---|---|---|
| E01 | 未配置 API Key | AI 入口置灰 + tooltip「先在设置里填写」 |
| E02 | Key 无效（401） | 「API Key 无效，请检查设置」+ 跳转设置 |
| E03 | 限流（429） | 「请求过于频繁，请稍后再试」+ 显示建议等待秒数 |
| E04 | 超时（30s） | 取消 + 「请求超时」，不自动重试超过 1 次 |
| E05 | 断网 | 快速失败（3s 内），提示检查网络 |
| E06 | 返回内容为空 | 「AI 没有返回结果」 |
| E07 | 返回内容超长 | 截断显示 + 「复制全部」 |
| E08 | 返回内容含 Markdown | 转纯文本显示（不做 Markdown 渲染，避免注入） |
| E09 | 模型名填错（404） | 「模型 xxx 不存在，请检查设置」 |
| E10 | 用户中途关闭面板 | 取消请求（`CancellationToken`） |

## F. 磁盘与文件

| # | 场景 | 处理 |
|---|---|---|
| F01 | 磁盘空间不足（备份失败） | 阻止写操作 + 「可用空间仅剩 X MB」+ 「清理旧备份」按钮 |
| F02 | 备份目录不可写 | 降级为「本次不备份」+ 明确警告「继续写入有风险」 |
| F03 | 路径含中文/空格 | 全部用 `Path` API，不用字符串拼接 |
| F04 | 路径超长（>260） | 启用 `\\?\` 前缀 |
| F05 | sidecar 文件被占用 | 重试 3 次 → 提示「请关闭占用程序」 |
| F06 | sidecar 损坏（非 sqlite 文件） | 改名备份 + 自动重建 + 「标签需重新整理」 |
| F07 | 日志目录写满 | 静默丢弃日志，不影响主流程 |

## G. 时间
