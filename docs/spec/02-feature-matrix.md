# 02 · 功能矩阵

> 优先级定义：**P0** = 没有它产品不成立 · **P1** = 核心闭环 · **P2** = v2 再做 · **P3** = 坚决不做

---

## P0 · 必须实现（缺一项产品不成立）

| # | 功能 | 实现方式 | 验收标准 | 限制 |
|---|---|---|---|---|
| F01 | 快速面板唤起 | 全局热键 `Ctrl+\`` + `RegisterHotKey` | 按键到面板可见 ≤ 300ms | 需 Ditto 释放该键 |
| F02 | 读取剪贴板历史 | SQLite `mode=ro` 打开 `Ditto.db` | 6,179 条首页加载 ≤ 20ms | 只读，不写 |
| F03 | 全文搜索 | `LIKE '%kw%'` 全表扫描 | 6 千条 ≤ 20ms / 5 万条 ≤ 80ms | 不支持正则的高性能（走 `re:` 时逐行匹配，允许慢） |
| F04 | 粘贴 | `Ditto.exe /paste:<id>` | 格式零损失（HTML/RTF/图片/文件） | 依赖 Ditto 运行 |
| F05 | 数字键直粘 | 按 `1`–`9` 直接粘第 N 条 | 与 Ditto `SendPasteOnFirstTenHotKeys` 行为一致 | — |
| F06 | 主界面 | 独立窗口，侧栏 + 单列列表 | 打开 ≤ 400ms | — |
| F07 | 分组切换 | `Tab` 树形浮层 + 「分组 ▾」按钮 | 35 个组全部可见可切 | — |
| F08 | Ditto 设置读写 | 解析 UTF-16 INI，P0 的 18 项 | 改完重启 Ditto 生效 | 按行编辑，不重写全文件 |
| F09 | 图片缩略图 | 解码 `CF_DIB` → 缩放 → 内存 LRU | 8.6MB 图首次 ≤ 150ms | 不落盘 |
| F10 | 中英双语 | `Strings.{lang}.json` | 切换后所有文案变化 | 首版两套 |
| F11 | 安全渲染 | 内容当纯文本；HTML 只做转义预览 | 复制含 `<script>` 的内容不执行 | 铁律 |
| F12 | 热键冲突检测 | 读 `Ditto.Settings` 的 `DittoHotKey` | 冲突时弹中文引导卡 | 需引导用户改 Ditto 设置 |

## P1 · 核心闭环

| # | 功能 | 实现方式 | 验收标准 |
|---|---|---|---|
| F13 | 标签系统 | `data/sidecar.db` 多对多 | 一条可挂多个标签 |
| F14 | 虚拟分组 | 查询式（今天/本周/图片/链接/未归类） | 切换 ≤ 50ms |
| F15 | 分组增删改 + 嵌套 | 写 `Main` 表（受控写入） | 旧界面同步可见 |
| F16 | 预览面板 | 行右侧 `⋯` → 346px 右滑 | 展开 ≤ 120ms |
| F17 | AI 语义搜索 | 用户配 Key 后可用 | 只发选中项；无 Key 时隐藏入口 |
| F18 | 敏感信息识别 | 本地正则（token/密码/身份证/银行卡） | 命中即在列表标红 + 提示 |
| F19 | 导入导出 | 四场景：换机打包 / 定时备份 / 导出选中 / 设置+标签 | 导出的包能在新机还原 |
| F20 | 深色模式 | 颜色 token 双套 | 跟随系统 + 手动覆盖 |
| F21 | 统计页 | 迁移 Ditto 的 Stats（复制次数/按天分布） | 读数与 Ditto 一致 |
| F22 | 来源应用记录 | 监听剪贴板 + `CRC` 对齐到 `lID` | 主界面可按来源过滤 |

## P3 · 坚决不做

| # | 不做 | 原因 |
|---|---|---|
| X01 | 云同步 | 用户明确不要；数据敏感 |
| X02 | 多机同步 | 同上 |
| X03 | 手机端 | 同上 |
| X04 | 密码管理 | 同上 |
| X05 | 插件机制 | 单人项目纯成本；需要时用 Ditto 原生 Addin |
| X06 | 内置分发 Ditto | 绕开 GPL 分发义务与体积膨胀 |
| X07 | 小白安装引导 | 目标用户已有 Ditto |
| X08 | 自建剪贴板监听器 | Ditto 已做得很好，重造必翻车 |
| X09 | 修改 Ditto 源码/重编译 | 见 D02 |

## 明确的功能边界（防止蔓延）

| 问题 | 答案 |
|---|---|
| 能不能在快速面板里建分组？ | 不能，去主界面或分组浮层 |
| 能不能在快速面板里改设置？ | 不能，只有「管理历史」入口 |
| AI 会不会自动跑？ | 不会，必须手动触发 |
| 会不会后台常驻网络连接？ | 不会，用完即断 |
| 会不会改 Ditto 的捕获规则？ | 不会，捕获完全交给 Ditto |
