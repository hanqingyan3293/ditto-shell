## 5. 界面 ④ 斜杠命令面板

原型：`docs/mockups/F-slash.html`

在搜索框输入 `/` 唤起，位于搜索行下方 8px，圆角 10，阴影第二级。

行结构：`[图标24] 中文名(13半粗) [别名 monospace灰] …… 示例值(11.5灰) ›`

分组标题：`最近使用` / `筛选器`，10px 大写间距。

底部条：`↑↓ 选择  ↵ 确定  Esc 关闭` + 右对齐「也可以继续打字直接搜」。

## 6. 状态定义（每个列表都必须有这 5 态）

| 状态 | 表现 |
|---|---|
| **加载中** | 骨架屏：3–5 条灰色圆角块，高度同行高，60% → 100% 透明度循环（1.2s） |
| **空（无历史）** | 居中图标 + 「还没有剪贴板历史」+ 「去复制点什么，这里会自动出现」 |
| **空（搜索无结果）** | 居中 + 「没找到含「xxx」的内容」+ 两个按钮：「清除筛选」「用 AI 搜索」 |
| **成功** | 正常列表 |
| **错误** | 顶部细条（高 32）：黄色警告 / 红色错误 + 说明 + 「重试」链接；**不遮挡列表** |

## 9. Win10 / Win11 差异处理

| 项 | Win11 | Win10 |
|---|---|---|
| 窗口背景 | Mica（`DWMWA_SYSTEMBACKDROP_TYPE`） | 纯色 + `SetWindowCompositionAttribute` 模糊（可选） |
| 圆角 | 系统原生 | **自绘**（`Clip` + `Border`） |
| 阴影 | 系统原生 | **自绘**（`DropShadowEffect` 两层） |
| 标题栏 | 可扩展绘制 | 完全自绘（`WindowStyle=None`） |

判定：`Environment.OSVersion.Version.Build >= 22000` → Win11。

## 10. DPI

- 支持 100% / 125% / 150% / 200%
- 全部尺寸用 DIP（设备无关像素），WPF 自动换算
- 图片按物理像素渲染（`RenderTargetBitmap` 用实际 DPI）
- 应用清单声明 `PerMonitorV2`
