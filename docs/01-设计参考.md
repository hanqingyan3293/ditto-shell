# 设计参考：snow-shot 的视觉语言（Ant Design 体系）

> 这个结论是查出来的，不是猜的：snow-shot 的界面不是自己随手设计的，
> 它用了 `ant_design_qt`（Ant Design 设计语言的 Qt 实现），所以我们能精确知道它的
> 圆角多少、间距多少、用哪个蓝。这套东西可以直接搬到 WPF，**不需要引入 Qt**。

---

## 1. 色板（从源码里提取，已核对）

| 用途 | 值 | 用在哪 |
|---|---|---|
| 主色 | `#1677FF` | 选中、主按钮、焦点框、链接 |
| 成功 | `#52C41A` | 健康状态、正向提示 |
| 警告 | `#FAAD14` | 待注意 |
| 错误 | `#FF4D4F` | 删除、危险操作 |
| 品红（点缀） | `#EB2F96` | 强调、标签 |
| 文本主色（浅色） | `#141414` | 正文 |
| 文本主色（暗色） | `rgba(255,255,255,0.85)` | 正文 |

### 文字层级（Ant Design 的透明度体系，非常好用）
| 层级 | 浅色模式 | 暗色模式 |
|---|---|---|
| 正文 | `rgba(0,0,0,0.88)` | `rgba(255,255,255,0.85)` |
| 次要 | `rgba(0,0,0,0.65)` | `rgba(255,255,255,0.65)` |
| 三级/说明 | `rgba(0,0,0,0.45)` | `rgba(255,255,255,0.45)` |
| 禁用 | `rgba(0,0,0,0.25)` | `rgba(255,255,255,0.25)` |

> 好处：一套颜色，靠透明度就拉出四个层级，暗色模式只改底色不改文本色。

### 背景与边框
| 用途 | 浅色 | 暗色 |
|---|---|---|
| 布局底 | `#F5F5F5` | `#000000` |
| 容器/卡片 | `#FFFFFF` | `#141414` |
| 浮层/弹窗 | `#FFFFFF` | `#1F1F1F` |
| 边框 | `#D9D9D9` | `#424242` |
| 分割线 | `#F0F0F0` | `#303030` |

## 2. 尺寸规范

| 项 | 值 | 说明 |
|---|---|---|
| 基础圆角 | **6px** | 卡片、按钮、输入框 |
| 大圆角 | 8px | 大卡片、面板 |
| 小圆角 | 4px | 小标签、徽标 |
| 基础字号 | 14px | 正文字号 |
| 字号阶梯 | 12 / 14 / 16 / 20 / 24 / 30 | 小字 / 正文 / 小标题 / 标题 / 大标题 |
| 基础行高 | 1.5714（14px → 22px） | 正文行高 |
| 控件高度 | 32px（默认） / 24（小） / 40（大） | 按钮、输入框 |
| 间距阶梯 | 4 / 8 / 12 / 16 / 24 / 32 / 48 | **以 8 为基本单位** |
| 卡片内边距 | 16px 或 24px | |

### 三级阴影（抄下来直接用）
```css
/* 一级：轻微浮起，用于卡片悬停 */
0 1px 2px rgba(0,0,0,0.03), 0 1px 6px -1px rgba(0,0,0,0.02), 0 2px 4px rgba(0,0,0,0.02)

/* 二级：面板、下拉 */
0 3px 6px -4px rgba(0,0,0,0.12), 0 6px 16px 0 rgba(0,0,0,0.08), 0 9px 28px 8px rgba(0,0,0,0.05)

/* 三级：模态框 */
0 6px 16px -8px rgba(0,0,0,0.08), 0 9px 28px 0 rgba(0,0,0,0.05), 0 12px 48px 16px rgba(0,0,0,0.03)
```

## 3. 映射到「剪贴板面板」的具体方案

| 部位 | 规范 |
|---|---|
| 面板窗口 | 圆角 8px，阴影二级，背景 = Win11 亚克力（`DwmSetWindowAttribute`），宽度 720–860px，最大高 70vh |
| 搜索框 | 高 40px，圆角 6px，无边框只留底色，左侧放大镜图标，右侧显示命中数 |
| 分组侧栏 | 宽 180px，条目高 32px，选中态 = 主色 10% 底 + 主色文字 |
| 条目卡片 | 高 64px（文本）/ 自适应（图片），圆角 6px，悬停阴影一级 + 主色 4% 底 |
| 类型标识 | 左侧 3px 竖色条：文本=主蓝、代码=紫、链接=青、图片=品红、文件=橙 |
| 元信息 | 14px 三级灰，格式：`来源 · 相对时间`（如「VSCode · 3 分钟前」） |
| 选中态 | 主色 10% 底 + 左侧主色竖条 + 键盘焦点环 2px |
| 空状态 | 居中插画 + 一行说明 + 「去复制点什么」提示 |
| 滚动条 | 宽 6px，圆角，悬停加深（不要系统默认那条粗灰） |

### 动效时长
| 动作 | 时长 | 曲线 |
|---|---|---|
| 面板弹出 | 120ms | ease-out + 轻微上移 8px |
| 面板收起 | 90ms | ease-in |
| 条目悬停 | 80ms | ease |
| 切换分组 | 150ms | ease-in-out |

## 4. 字体

| 用途 | 推荐 |
|---|---|
| 中文 | `MiSans` / `HarmonyOS Sans SC` / 微软雅黑（兜底） |
| 英文数字 | `Inter` / `Segoe UI`（系统自带，兜底） |
| 代码 | `JetBrains Mono` / `Cascadia Code`（Win11 自带） |

> 字体文件不进项目，优先用系统已有；找不到就回落到 Segoe UI + 微软雅黑。

## 5. 这份文档怎么用

- UI 阶段，所有颜色/尺寸/阴影 **从这张表里取，不即兴发挥**。
- 换主题只需换第 1 节的色板，第 2 节保持不变 → 保证一致性。
- 如果想要更"高级"的观感，加到第 3 节的映射表里讨论，不要破坏 token 体系。
