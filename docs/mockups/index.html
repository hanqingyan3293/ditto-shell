DittoShell · 四个界面方案

全部按 Ant Design 设计体系（主色 #1677FF / 圆角 6px / 8 的倍数间距）绘制 · 点击标题可打开交互原型

方案 A · 侧栏 + 单列 稳

最接近 Ditto 的使用习惯，左侧固定分组栏，右侧单列卡片流。

  • 优点：分组一眼看全，信息密度高，学习成本最低
  • 缺点：右侧只显示一列，图片预览小

打开原型 →

方案 B · 顶部搜索 + 横滑分组 + 网格 最像 snow-shot

顶部大搜索框，分组做成横滑胶囊，内容用双列卡片网格。

  • 优点：视觉最现代，图片/长文本有呼吸感，搜索框最突出
  • 缺点：分组多时胶囊会挤，需要横向滚动

打开原型 →

方案 C · 三栏（分组 / 列表 / 预览） 强

左分组、中列表、右预览，选中即可看全文、格式、粘贴次数。

  • 优点：找东西最快，"这条到底是什么"一目了然
  • 缺点：窗口要宽（1000px+），小屏或低分辨率偏挤

打开原型 →

方案 D · 极简命令面板 轻

没有侧栏，只有搜索 + 结果 + 底部胶囊，键盘优先（Raycast 风）。

  • 优点：最轻最快，弹出无负担，纯键盘操作
  • 缺点：不适合"浏览"和"整理"，分组只是底部一行
