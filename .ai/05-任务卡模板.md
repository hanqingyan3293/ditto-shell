# 任务卡模板

> 每个开发任务开始前，AI 先填这张卡，用户点头后再动手。
> 目的：用户不需要看懂代码，但要能看懂「这次要动什么、有什么后果」。

---

```
══════════════════════════════════════════════
任务卡 #NNN
══════════════════════════════════════════════

【一句话目标】
（用户能看懂的一句话，不要出现函数名）

【所属阶段】
阶段 1 / 2 / 3 / 4

【会动到的东西】
□ 新建文件：
□ 修改文件：
□ 读取（不改）：Ditto.db / reference/
□ ⚠️ 写入 Ditto.db：（有则写清备份文件名）

【不会动的东西】
（明确列出「这次不碰」的范围，让用户放心）

【验收标准】
1. 一条命令能验证：
2. 一个点击能验证：
3. 预期输出：

【回滚方法】
一条命令 或 一个操作：

【预估风险】
低 / 中 / 高 —— 风险点在哪，出问题最坏结果是什么

【需要用户确认】
- 是 / 否
══════════════════════════════════════════════
```

---

## 填写示例

```
任务卡 #001
【一句话目标】做一个能弹出的空面板，按下 Ctrl+` 就出现，按 Esc 就消失
【所属阶段】阶段 1
【会动到的东西】
□ 新建文件：src/DittoShell/App.xaml, MainWindow.xaml
【不会动的东西】Ditto 的任何文件、reference/、数据库
【验收标准】
1. 命令：dotnet run --project src/DittoShell
2. 点击：按 Ctrl+` ，面板出现在屏幕中央偏上
3. 预期：圆角、半透明、无标题栏、Esc 关闭
【回滚方法】删除 src/DittoShell 目录
【预估风险】低 —— 只是空窗口，不接触任何数据
【需要用户确认】- 是 / 否
```
